## Current interpretation

1. Baseline differs materially across machines and modules; fleet-level raw thresholds are not defensible.
2. One-minute aggregation retains broad association but cannot recreate the complete one-second trajectory. Minute records can carry derived response summaries computed from the one-second ring buffer.
3. Existing clean event data represent closing behavior under SV Off almost exclusively. Opening and SV On event models are `INSUFFICIENT_COVERAGE`.
4. The 120-second hybrid feature set currently has too many features relative to event count and shows cross-machine instability.
5. The correct production direction is a state-aware hybrid system with local calibration, an explainable fleet detector, persistence logic, and human verification.
6. Research supports beginning with shadow/advisory anomaly screening; it does not support automatic leak diagnosis from the current labels/context.
7. Every model benchmark must retain a simple/statistical baseline and use nested temporal/group selection without touching outer tests.
8. Auto-bootstrap profile, statistical bootstrap, model bagging and AutoML/HPO are separate mechanisms.
