## Current decision

แนวทางให้คะแนนหลักที่เจ้าของโครงการเลือกสำหรับระยะปัจจุบันคือกฎเดียวจาก Active Profile:

```text
Data/State Gate
→ human-approved state-conditioned Active Profile
→ nine relative robust-z features
→ max absolute z-score + temporal persistence
→ human maintenance review
```

ARX, Isolation Forest, Peer, LSTM/TCN เป็น challenger/research เท่านั้น ไม่ใช่ production default หรือคะแนนที่ถูกนำไปรวมใน alert ปัจจุบัน เพราะยังไม่มีหลักฐาน incremental value/coverage และการทดสอบ Server ที่เพียงพอ


Production direction แยกเป็นสองระดับ: เริ่มได้ที่ shadow/technician-advisory anomaly screening หลัง lifecycle gates ผ่าน แต่ automatic leak diagnosis ยังถูกบล็อกด้วย labels และ operating context ที่ขาดอยู่
